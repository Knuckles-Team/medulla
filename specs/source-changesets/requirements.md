| `MEDULLA-SCM-R001` | **Content-addressed blob store.** Stage: served method `SubmitChangeset`, blob phase. Each file version is a blob keyed by its content digest. Identical bytes store once. Bytes reach the store before the changeset, through the existing `BlobBegin`, `BlobChunkPut` and `BlobCommit` methods (`crates/medulla-protocol-types/src/protocol/method/method_06.rs`); `BlobCommit` returns the digest. `SubmitChangeset` carries no bytes, only `SubmittedBlobRef { digest: String, size: u64 }`, where `digest` is the value `BlobCommit` returned and `size` counts bytes from 0 to `changeset_max_blob_bytes`,, defined in `crates/medulla-types/src/source_changeset.rs`. `accept_blobs(refs: &[SubmittedBlobRef])` checks each ref: an unknown digest refuses `BLOB_NOT_FOUND`; a stored length different from `size`, or a digest that `stream_blob_get` re-derives differently, refuses `BLOB_DIGEST_MISMATCH`; a `size` over the limit refuses `BLOB_TOO_LARGE` before any read. Caller: `Method::SubmitChangeset` → `crates/medulla-h-ingest/src/source_changeset.rs::accept_blobs` → `stream_blob_put` at `crates/medulla-server-blob/src/blob/stream.rs:35`, which writes through the chunk store `crates/medulla-server-blob/src/blob/store.rs`. A read calls `stream_blob_get` at `stream.rs:90` by digest. A second write of the same bytes returns the same digest and adds no storage. Limit: `SchedulerConfig.changeset_max_blob_bytes` default 134217728, range [1048576, 4294967296], unit bytes. The record class is sealed and create-only (`MEDULLA-DURABLE-KERNEL-R057`). Refusals: `BLOB_DIGEST_MISMATCH` when declared and recomputed digests or sizes differ, `BLOB_TOO_LARGE`, `BLOB_NOT_FOUND` for an unreadable digest. Depends on: none. Caller chain: served method → `crates/medulla-server-graph/src/dispatch/graph_pipeline/native_routes.rs` (beside the `SourceIngest` arms at line 399) → `crates/medulla-h-ingest/src/source_changeset.rs::accept_blobs` → `stream_blob_put` (`crates/medulla-server-blob/src/blob/stream.rs:35`); a read calls `stream_blob_get` (line 90). Shape: new `accept_blobs` in new `crates/medulla-h-ingest/src/source_changeset.rs`, reusing `stream_blob_put`, `stream_blob_get` and the chunk store in `crates/medulla-server-blob/src/blob/store.rs`; the knob `changeset_max_blob_bytes` is a field of `SchedulerConfig` in `crates/medulla-types/src/scheduler_config.rs:30`; the refusals are variants of one `ChangesetRefusal` enum in the same new file. | Test: `tests/test_scm_blob.py::test_blob_stored_once_and_read_by_digest` (L3).
