# MEDULLA-CONTRACT — Test specification

Tests are keyed to the published commit. The baseline suite starts a disposable local Medulla instance and builds its own fixtures. External services are optional deployment qualification, not a pull request prerequisite.

## Proof levels

| Level | Harness |
|---|---|
| L1 Unit | A `#[cfg(test)]` module, a crate test or a `pytest` unit test |
| L2 Property, vector and gate | Committed vectors, gate fixtures and mutation fixtures |
| L3 Served | A served engine or an installed wheel, entered through the production boundary |
| L4 Served client | `tests/*_served.py` over a loopback engine with authentication |
