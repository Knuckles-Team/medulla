# MEDULLA-CLUSTER — Requirements

Governing spec: [spec.md](spec.md).

Each row is one requirement. A child row `.n` is one five-minute unit of work. A row names the file it touches, its caller chain, its Shape sentence, its budget and the test that proves it as `path::name`. The generator sets each row's state.

Terms used in every row. The *kernel* is the module `crates/medulla-numeric/src/cluster/`. *E-means* is the kernel algorithm: seeded mini-batch updates with moving-average centroids. *Exact mode* is the full-batch mode of the same kernel. A *step* is one mini-batch update, or one full pass in exact mode. A *run* is one call of `cluster::fit`. A *knob* is a `KnobSpec` row of `MEDULLA-DECISION-ENGINE-R179.1`. *Cluster* never means a group of engine nodes.
