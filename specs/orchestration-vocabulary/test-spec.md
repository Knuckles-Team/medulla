Positive: each term resolves and the reasoner stays consistent. Each Q1-Q7 query returns fixture rows. Negative: plant one invalid fixture per shape. Cover `:precedes` cycle and `swarm:feeds` cycle. Cover slot with non-kind, member without capability, rule without class, and agent without model. Vocabulary tests live in `crates/medulla-rdf/tests/orchestration_vocabulary.rs` (modules `run_trace` and `vocabulary`). Fixtures live in `crates/medulla-core/tests/fixtures/orchestration_vocabulary/`.

Assembly-kind acceptance: a verifier-constrained slot excludes an executor-only candidate, accepts a visible verifier, and yields typed abstention without one.

Harness run-trace acceptance: a valid trace per termination reason round-trips through the client and `AddNode`. The engine refuses a negative counter, an unknown reason, and a peak above budget without `context_overflow`. A `ModelProfile` publish whose measured fact has no evaluation run is refused (MEDULLA-TYPED-PACKS-R048.2). A newer measurement is a newer `ModelProfile` revision, and the older revision stays readable. Spec-folder mapping: a fixture folder through `IndexRepository` yields one node of each kind. An unknown file is refused and stored as a plain document. Every node names its deciding rule.
